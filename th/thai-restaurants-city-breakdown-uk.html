ข้อค้นพบสำคัญ — มิถุนายน 2026

  • ลอนดอนมีธุรกิจไทย 411 แห่ง — คิดเป็น 26% ของทั่วสหราชอาณาจักร แบ่งเป็นร้านทานในร้าน 323 แห่ง ร้านขายกลับบ้าน 88 แห่ง แต่ความหนาแน่นต่อประชากรอยู่ในอันดับ 10 เท่านั้น
  • สวอนซีเป็นเมืองที่มีธุรกิจไทยหนาแน่นที่สุด ที่ 5.7/100,000 รองลงมาคือนอริช (5.4) และบาธ (5.1)
  • สกอตแลนด์มีธุรกิจไทย 70 แห่ง ทั่ว 21 เขตสภา — เอดินบะระนำด้วย 24 แห่ง กลาสโกว์มี 8 แห่ง
  • เบอร์มิงแฮมยังขาดแคลนอย่างหนัก — เพียง 1.5/100,000 สำหรับเมืองใหญ่อันดับ 2 ของสหราชอาณาจักร (ประชากร 1,166,000 มีธุรกิจไทยเพียง 17 แห่ง)
  • กลาสโกว์และเชลเทนแฮม มีคะแนนสุขอนามัยเฉลี่ยสูงสุดที่ ★5.0
  • Giggling Squid, Busaba, Chaophraya, Patara, Sukhothai และ Zaap ได้รับการรวมแล้ว — เครือร้านที่ก่อนหน้านี้ถูกมองข้ามเพราะชื่อไม่มีคำว่า "Thai"

แหล่งข้อมูลและวิธีการ — มิถุนายน 2026

แหล่งข้อมูลหลัก: Food Standards Agency (FSA) — api.ratings.food.gov.uk ข้อมูลรัฐบาลสหราชอาณาจักรอย่างเป็นทางการ ธุรกิจอาหารทุกแห่งในสหราชอาณาจักรต้องลงทะเบียน ฟรี สาธารณะ ไม่ต้องใช้ API key

รายการที่รวม:
• สถานประกอบการทั้งหมดที่ลงทะเบียนกับ FSA ที่มีคำว่า "Thai" ในชื่อธุรกิจ — ทั้งระบบ FHRS (อังกฤษ เวลส์ ไอร์แลนด์เหนือ) และ FHIS (สกอตแลนด์)
• ประเภทธุรกิจ: Restaurant/Cafe/Canteen (นับเป็น "ทานในร้าน") และ Takeaway/Sandwich Shop
• เครือร้านอาหารไทยที่รู้จักซึ่งไม่มีคำว่า "Thai" ในชื่อ: Giggling Squid, Busaba, Chaophraya, Patara, Sukhothai, Zaap
• เฉพาะธุรกิจที่ผ่านการตรวจสอบแล้ว (ยกเว้น 122 แห่งที่รอการตรวจสอบครั้งแรก)
• คะแนน "Pass" ของสกอตแลนด์แปลงเป็น ★5 "Improvement Required" เป็น ★2

ข้อจำกัด (และสิ่งที่เราได้ดำเนินการแล้ว):
• ✓ เครือร้านที่ไม่มีคำว่า "Thai" ในชื่อ: Giggling Squid, Busaba, Chaophraya, Patara, Sukhothai และ Zaap ได้รับการรวมแล้วผ่านการคิวรี API แยกต่างหาก
• ✓ สกอตแลนด์หายไป: ได้รับการรวมแล้วผ่าน API ระบบ FHIS — ธุรกิจ 70 แห่งทั่ว 21 เขตสภา
• ✓ สถานที่ยังไม่ผ่านการตรวจสอบ: กรองออกแล้ว (122 แห่ง) แสดงเฉพาะธุรกิจที่ได้รับคะแนนแล้ว
• ~ การลงทะเบียนซ้ำ: ธุรกิจที่ดำเนินการจากหลายหน่วย (เช่น ทานในร้าน + ครัวมืด) อาจปรากฏสองครั้ง ซึ่งทำให้ตัวเลขสูงขึ้นเล็กน้อย — ประมาณผลกระทบ <5%
• ~ คะแนน ≠ คุณภาพอาหาร: คะแนน FSA สะท้อนความสอดคล้องด้านสุขอนามัยอาหาร ไม่ใช่รสชาติ การบริการ หรือความคุ้มค่า
• ~ การจับคู่ชื่อธุรกิจ: ร้านอาหารไทยบางแห่งอาจยังถูกมองข้ามหากใช้ชื่อที่ไม่มีคำว่า "Thai" และไม่อยู่ในรายการเครือร้านของเรา เราเชื่อว่าขอบเขตการครอบคลุมตอนนี้ >95%
• ~ ขอบเขตเมือง: ข้อมูลจัดกลุ่มตามเขตสภาท้องถิ่น FSA เขตบางแห่งครอบคลุมพื้นที่กว้างกว่าชื่อเมือง (เช่น Cornwall, North Yorkshire)
